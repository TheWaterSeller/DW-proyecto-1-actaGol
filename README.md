# ActaGol

ActaGol es una organización que coordina campeonatos, tanto amateur como formativo, donde en cada competencia se reúnen árbitros. equipos y jugadores, requiriendo el registro de lo ocurrido en cada partido.

## El problema
Dentro de un partido, un gol, tarjeta o cambio puede quedar anotado de forma incompleta, si se modifica el acta después del cierre, esta puede no quedar registrado el cambio ni su justificación
## La solución
Lo que busca la plataforma web de ActaGol es que cada arbitro pueda confirmar los equipos y planteles de un partido antes de que empiece, registrar los eventos ocurridos en el partido mientras esta en curso y emitir una acta al finalizar el mismo. Además, la plataforma permite el inicio de partidos, la mantención cronológica de el marcador y estado de los jugadores, el cierre del encuentro y consultar el historial, estadísticas y correciones autorizadas de partidos.

# Uso
Una vez ingresado a la plataforma (ya sea como arbitro, coordinador o administrador), se podran ver partidos proximos, o que ya han terminado. Posteriormente se pueden ver el detalle de los mismos, donde van a ocurrir, entre que equipos va a ocurrir, los arbitros involucrados y el plantel, el cual permite validar los titulares, suplentes, dorsales y capitanes.
